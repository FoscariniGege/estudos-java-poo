# ☕ Exercícios de Java - Matrizes (Arranjos Bidimensionais)

Este repositório guarda os meus primeiros passos com matrizes em Java, focando especificamente na manipulação de matrizes quadradas de ordem N, propriedades de índices de coordenadas e filtragem condicional de elementos. 

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Declaração, alocação e iteração de matrizes bidimensionais quadradas
- Leitura e exibição formatada de linhas e colunas através de laços aninhados
- Acesso otimizado à diagonal principal utilizando índice unificado (`matriz[i][i]`)
- Varredura completa da matriz com contagem de valores negativos

*(Nota de evolução: Transição definitiva da manipulação linear com vetores para coordenadas bidimensionais de memória, trabalhando indexação de linhas e colunas).*

## 💻 Exercícios Resolvidos

1. **Matriz Quadrada - Diagonal Principal e Negativos**: Lê uma matriz de ordem $N$, exibe a formatação das linhas, imprime os números pertencentes à diagonal principal e calcula o total de números inteiros negativos contidos na tabela.
