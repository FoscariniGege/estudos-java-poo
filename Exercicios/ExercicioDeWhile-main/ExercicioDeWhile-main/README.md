# ☕ Exercícios de Java - Laço While

Este repositório guarda os meus primeiros passos com estruturas de repetição em Java, focando especificamente no laço `while`. 

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, antes de eu aprender técnicas de otimização e Clean Code (como restringir escopo de variáveis e usar `printf`). O objetivo principal aqui era **fazer a lógica funcionar** e entender o conceito de repetição condicional.

Nesta etapa, eu apliquei:
* **Estrutura `while`**: Como manter o programa rodando indefinidamente até que uma "condição de parada" seja atendida (ideal para quando não sabemos quantas vezes o usuário vai digitar algo).
* **Entrada contínua de dados**: Uso do `Scanner` dentro do loop para ler informações várias vezes.
* **Lógica de menus e opções**: Uso de `if/else` combinados com o laço para registrar diferentes categorias de dados (como os tipos de combustível).

*(Nota de evolução: Como estes foram meus primeiros códigos de repetição, eles utilizam formatações simples de texto e escopos mais amplos de variáveis, refletindo a base do meu aprendizado passo a passo!)*

## 💻 Exercícios Resolvidos

1. **Validação de Senha**: Um programa que repete a leitura de uma senha até que o usuário digite o valor correto (simulando um bloqueio de sistema).
2. **Plano Cartesiano (Quadrantes)**: Leitura contínua de coordenadas X e Y para identificar em qual quadrante o ponto se encontra. O programa para automaticamente quando um dos valores for zero.
3. **Posto de Combustível**: Um pequeno sistema de pesquisa para ler códigos numéricos correspondentes aos combustíveis abastecidos (1-Álcool, 2-Gasolina, 3-Diesel) e, ao digitar o código de parada (4), imprimir um relatório com o total de cada um.

## 🛠️ Tecnologias Utilizadas

* Java
* Ferramentas nativas: `Scanner` (para leitura de dados no terminal)
