☕ Exercícios de Java - Controle de Estoque com Orientação a Objetos
Este repositório guarda a minha evolução na Programação Orientada a Objetos (POO) em Java, focando em modelagem de classes, encapsulamento de comportamentos e boas práticas de formatação.

🚀 O que eu estava aprendendo
Nesta etapa, o foco foi sair da estrutura básica e criar um sistema real onde os objetos possuem seus próprios dados e ações. Aprendi a estruturar uma classe de ponta a ponta e a utilizá-la de forma limpa no programa principal.

Nesta etapa, eu apliquei:

Criação de Atributos e Métodos de Instância: Modelar uma classe Product com propriedades (name, price, quantity) e comportamentos próprios.

Lógica de Negócio na Entidade: Métodos para calcular o valor total em estoque (TotalValueStock), adicionar itens (AddProducts) e remover itens (RemoveProducts) diretamente no objeto.

O poder do toString(): Substituir métodos auxiliares de impressão por uma representação em texto nativa da classe, permitindo que o objeto se descreva sozinho com um simples System.out.println().

(Nota de evolução: Com o uso do toString() e a separação correta entre a aplicação (Program) e a entidade (Product), o código ficou muito mais limpo, organizado e alinhado com os padrões de mercado (Clean Code)!)

💻 Exercícios Resolvidos
Controle de Estoque (Product): Um programa completo que lê os dados iniciais de um produto, calcula o valor total investido no estoque, e permite realizar entradas e saídas de mercadorias, atualizando e exibindo o estado atualizado do produto a cada operação.

🛠️ Tecnologias Utilizadas
Java

Ferramentas nativas: Scanner (para entrada de dados) e formatação avançada de strings (String.format)

Conceitos de POO: Classes, encapsulamento, métodos de instância e o método especial toString()
