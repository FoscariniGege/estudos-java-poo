# ☕ Exercícios de Java - Estruturas de Dados: Fila Estática Circular

Este repositório guarda os meus primeiros passos com estruturas de dados em Java, focando especificamente na implementação do Tipo Abstrato de Dados (TAD) Fila através de vetores lineares estáticos, controle de ponteiros circulares e interface interativa via console.

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Arquitetura em camadas simples: separação entre a entidade de dados (`entities.FilaEstatica`) e a aplicação interativa (`application.Program`)
- Princípio FIFO (*First-In, First-Out*) com capacidade limitada a 20 elementos inteiros
- Lógica circular com o operador de módulo (`%`) para reaproveitamento dos índices do vetor
- Criação de menu CLI no terminal com laço `do-while` e estrutura de controle `switch-case`
- Prevenção de efeitos colaterais de fluxo como o *fall-through* em blocos condicionais

*(Nota de evolução: Saída dos exercícios lineares de console para a criação de programas interativos completos orientados a menu, gerenciando estados dinâmicos de estruturas na memória).*

## 💻 Exercícios Resolvidos

1. **Fila Estática com Menu Interativo**: Implementação e testes de todas as operações primitivas de uma fila linear estática circular (inserção, remoção, inspeção de frente, checagem de vazio/cheio e tamanho total) via terminal.

## 🛠️ Tecnologias Utilizadas

- Java
- Ferramentas nativas: `Scanner`
- Programação Orientada a Objetos (POO)
