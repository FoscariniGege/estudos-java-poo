# ☕ Exercícios de Java - Laço For

Este repositório guarda os meus exercícios práticos de Java. O foco desta etapa foi treinar o uso do laço de repetição `for` e melhorar a lógica de programação.

## 🚀 O que eu aprendi e apliquei

Durante a resolução desses desafios, tentei focar não só em fazer funcionar, mas em deixar o código mais limpo e organizado. Algumas coisas legais que apliquei:

* **Estrutura `for`**: Como repetir ações e ler vários dados em sequência.
* **Escopo de Variáveis**: Aprendi a declarar as variáveis apenas onde elas são usadas (dentro do laço), para economizar memória e deixar o código mais organizado.
* **Formatação com `printf`**: Uso do `%d` para inteiros, `%.1f` para controlar as casas decimais e o `%n` para quebrar as linhas.
* **Locale.US**: Dica essencial para fazer o `Scanner` aceitar números com ponto (ex: 6.5) em vez de dar erro esperando uma vírgula.
* **Proteção de erros**: Usar `if` para evitar operações impossíveis, como a divisão por zero.
* **Lógica com Acumulador**: Como resolver cálculos como o de Fatorial de um jeito mais simples, começando a variável com 1.

## 💻 Exercícios Resolvidos

1. **Intervalos**: Lendo uma quantidade N de números e contando quantos estão dentro do intervalo [10, 20] e quantos estão fora.
2. **Média Ponderada**: Calculando a média de 3 valores reais com pesos diferentes.
3. **Divisão Segura**: Lendo pares de números para dividir, mas mostrando a mensagem "divisao impossivel" caso o denominador seja zero.
4. **Fatorial**: Calculando o fatorial de um número N.
5. **Divisores**: Lógica para encontrar e imprimir todos os divisores exatos de um número.
6. **Quadrado e Cubo**: Imprimindo uma sequência de números junto com o seu quadrado e o seu cubo.

## 🛠️ Tecnologias Utilizadas

* Java
* Ferramentas nativas: `Scanner` (para entrada de dados)
