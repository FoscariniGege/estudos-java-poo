# ☕ Exercícios de Java - Listas, Objetos e Encapsulamento

Este repositório guarda os meus primeiros passos com listas dinâmicas em Java, focando especificamente na manipulação de coleções de objetos com List/ArrayList, regras de integridade de dados e arquitetura em camadas. 

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Arquitetura desacoplada em pacotes (`application`, `entities` e `util`)
- Uso de `List` e `ArrayList` para gerenciar coleções dinâmicas sem tamanho fixo
- Proteção de dados com encapsulamento (salário alterável exclusivamente por regra de porcentagem)
- Métodos utilitários estáticos para busca linear de entidades por identificador
- Validação de unicidade de ID e controle de fluxo com laços e condicionais

*(Nota de evolução: Saída dos vetores fixos para coleções dinâmicas da API Java, aplicando validações de integridade e modularização de código).*

## 💻 Exercícios Resolvidos

1. **Cadastro e Reajuste Salarial de Funcionários**: Leitura de dados de $N$ colaboradores impedindo IDs duplicados, busca por ID para aplicação de aumento percentual controlado e exibição final da lista formatada via `toString()`.

## 🛠️ Tecnologias Utilizadas

- Java
- Java Collections Framework (`List`, `ArrayList`)
- Ferramentas nativas: `Scanner`, `Locale`
