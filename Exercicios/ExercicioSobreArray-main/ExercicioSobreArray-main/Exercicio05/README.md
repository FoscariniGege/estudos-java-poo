# ☕ Exercícios de Java - Vetores e Busca de Extremos

Este repositório guarda os meus primeiros passos com arrays unidimensionais (vetores), focando especificamente em leitura de dados em ponto flutuante e identificação de valores máximos e índices de posição.

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Vetores de tipos primitivos em ponto flutuante (`double[]`)
- Algoritmo de busca linear para elemento de maior valor
- Rastreamento e retenção de índice do vetor (`array index`)
- Separação entre laços de entrada e laços de processamento lógico

*(Nota de evolução: O código reforça o tratamento de valores limítrofes, evitando inicializações arbitrárias e assumindo o primeiro item da coleção como referência de comparação).*

## 💻 Exercícios Resolvidos

1. **Maior Posição**: Lê $N$ números reais, armazena-os em um vetor e determina tanto o maior valor presente quanto a posição (índice) exata em que ele se encontra.

## 🛠️ Tecnologias Utilizadas

- Java
- Ferramentas nativas: `Scanner`, `Locale`, arrays primitivos
