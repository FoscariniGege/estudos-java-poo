# ☕ Exercícios de Java - Operações com Múltiplos Vetores

Este repositório guarda os meus primeiros passos com manipulação simultânea de múltiplos arrays unidimensionais (vetores), focando na sincronização de índices e separação de responsabilidades na arquitetura do código.

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Leitura e preenchimento de múltiplos vetores de mesmo tamanho
- Acesso posicional correspondente entre diferentes coleções indexadas
- Separação clara entre etapas de entrada, processamento matemático e exibição
- Boas práticas com tipos primitivos (`int[]`) e convenções de estilo Java

*(Nota de evolução: O código reforça a clareza da regra de negócio, priorizando operações explícitas e manuteníveis em vez de acumulações implícitas durante a fase de leitura).*

## 💻 Exercícios Resolvidos

1. **Soma de Vetores**: Lê dois vetores distintos ($A$ e $B$) com $N$ elementos cada, gera um terceiro vetor $C$ contendo a soma dos elementos em suas posições homólogas e imprime os valores resultantes.

## 🛠️ Tecnologias Utilizadas

- Java
- Ferramentas nativas: `Scanner`, arrays primitivos
