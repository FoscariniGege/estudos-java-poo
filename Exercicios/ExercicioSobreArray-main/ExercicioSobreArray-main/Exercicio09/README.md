# ☕ Exercícios de Java - Vetores Paralelos

Este repositório guarda os meus primeiros passos com arrays unidimensionais paralelos, focando especificamente no relacionamento de dados heterogêneos indexados e no controle do buffer de entrada do teclado.

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Gerenciamento de múltiplos vetores sincronizados por índice (`String[]` e `int[]`)
- Controle e limpeza do buffer de quebra de linha do `Scanner` (`nextLine()` após `nextInt()`)
- Algoritmo de busca de valor máximo com iteração a partir do índice 1
- Recuperação de atributos associados através de índice relacional

*(Nota de evolução: O código demonstra maior maturidade no tratamento de referências iniciais de comparação e reforça a importância da consistência na leitura de entradas de texto e valores numéricos intercalados).*

## 💻 Exercícios Resolvidos

1. **Mais Velho**: Lê o nome e a idade de $N$ pessoas armazenando-os em vetores distintos e paralelos, identifica a pessoa com a maior idade e exibe seu respectivo nome na tela.

## 🛠️ Tecnologias Utilizadas

- Java
- Ferramentas nativas: `Scanner`, arrays primitivos e objetos (`String[]`, `int[]`)
