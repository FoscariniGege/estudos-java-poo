# ☕ Exercícios de Java - Vetores e Filtros Condicionais

Este repositório guarda os meus primeiros passos com arrays unidimensionais (vetores), focando especificamente em agregação de valores filtrados, prevenção de exceções em tempo de execução e manipulação de precisão em ponto flutuante.

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Leitura e iteração de vetores inteiros (`int[]`)
- Filtros condicionais baseados no operador módulo (`%`)
- Prevenção ativa de divisão por zero (`ArithmeticException`)
- Casting numérico explícito (`(double)`) para evitar truncamento em divisão inteira
- Tratamento de casos de exceção de negócio quando nenhum registro atende ao critério

*(Nota de evolução: O código destaca a importância de ordenar as operações com base nas condições de guarda, garantindo que operações aritméticas sensíveis só aconteçam com dados válidos).*

## 💻 Exercícios Resolvidos

1. **Média dos Pares**: Lê um vetor de $N$ números inteiros, calcula e exibe a média aritmética formatada com uma casa decimal exclusivamente para os números pares informados. Caso nenhum número par seja digitado, trata o fluxo informando a mensagem correspondente.

## 🛠️ Tecnologias Utilizadas

- Java
- Ferramentas nativas: `Scanner`, `Locale`, arrays primitivos
