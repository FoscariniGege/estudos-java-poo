# ☕ Exercícios de Java - Vetores (Arrays)

Este repositório guarda os meus primeiros passos com vetores em Java, focando especificamente na manipulação de memória, acumulação de valores e cálculo de métricas estatísticas simples. 

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Vetores de tipos primitivos inteiros (`int[]`) e reais (`double[]`)
- Variáveis acumuladoras para cálculo de soma e média
- Formatação de saída com casas decimais usando `printf`
- Separação lógica entre entrada de dados e processamento de informações

*(Nota de evolução: Transição do armazenamento simples para algoritmos de agregação e estatística com arrays).*

## 💻 Exercícios Resolvidos

1. **Problema Negativos**: Lê $N$ números inteiros, armazena-os num vetor e exibe apenas os valores negativos.
2. **Problema Soma Vetor**: Lê $N$ números reais, imprime todos os elementos armazenados e calcula a soma total e a média aritmética dos valores.

## 🛠️ Tecnologias Utilizadas

- Java
- Ferramentas nativas: `Scanner`, `Locale`
