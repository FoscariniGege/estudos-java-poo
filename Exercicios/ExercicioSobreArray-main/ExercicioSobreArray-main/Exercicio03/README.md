# ☕ Exercícios de Java - Vetores (Arrays) e Objetos

Este repositório guarda os meus primeiros passos com vetores e Programação Orientada a Objetos em Java, focando especificamente na modelação de entidades e manipulação de conjuntos de dados compostos em memória. 

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Vetores de tipos primitivos (`int[]`, `double[]`) e vetores de tipos referência/objetos (`Pessoa[]`)
- Instanciação de instâncias dentro de ciclos e acesso a atributos
- Gestão do buffer de leitura do `Scanner` (`nextLine()` após leitura numérica)
- Cálculo de percentagens com conversão explícita de tipos (`casting`) para ponto flutuante

*(Nota de evolução: Transição fundamental do armazenamento de dados primitivos para arrays de entidades estruturadas, integrando conceitos de classes e objetos).*

## 💻 Exercícios Resolvidos

1. **Problema Negativos**: Lê $N$ números inteiros, armazena-os num vetor e exibe apenas os valores negativos.
2. **Problema Soma Vetor**: Lê $N$ números reais, imprime todos os elementos armazenados e calcula a soma total e a média aritmética dos valores.
3. **Problema Alturas**: Lê os dados (nome, idade e altura) de várias pessoas num vetor de objetos, calculando a altura média e a percentagem de indivíduos com menos de 16 anos, listando os seus nomes.

## 🛠️ Tecnologias Utilizadas

- Java
- Ferramentas nativas: `Scanner`, `Locale`
