# ☕ Exercícios de Java - Análise de Dados com Objetos

Este repositório guarda os meus primeiros passos com processamento analítico de vetores de entidades em Java, focando especificamente em busca de extremos, categorização condicional por atributos e cálculo de médias parciais.

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Manipulação de vetores de classes customizadas (`Pessoa[]`)
- Busca linear simultânea de valor máximo e mínimo com referência inicial no índice zero
- Padronização de entradas de caracteres alfanuméricos com `Character.toUpperCase`
- Separação criteriosa de laços para algoritmos com requisitos de iteração distintos (índice 1 para extremos vs índice 0 para contadores globais)
- Tratamento de condições de contagem zerada para evitar divisão inválida

*(Nota de evolução: O código enfatiza a atenção aos limites dos laços de repetição e o cuidado com a integridade dos dados ao agregar múltiplos filtros sobre uma mesma coleção).*

## 💻 Exercícios Resolvidos

1. **Dados Pessoas**: Lê a altura e o gênero ($M$ ou $F$) de $N$ pessoas, determina a maior e a menor altura do grupo inteiro, calcula a média de altura exclusivamente entre as mulheres e totaliza a contagem de homens.

## 🛠️ Tecnologias Utilizadas

- Java
- Ferramentas nativas: `Scanner`, `Locale`, `Character`, Orientação a Objetos (`Pessoa`)
