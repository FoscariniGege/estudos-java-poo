# ☕ Exercícios de Java - Vetores e Filtragem

Este repositório guarda os meus primeiros passos com manipulação de arrays unidimensionais (vetores), focando especificamente em entrada de dados, verificação condicional de paridade e contadores.

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Declaração e instanciação de vetores primitivos (`int[]`)
- Iteração e controle de limites via `array.length`
- Lógica condicional com operador aritmético de resto de divisão (`%`)
- Variáveis contadoras acumuladoras

*(Nota de evolução: O código demonstra a transição do entendimento básico de memória sequencial para filtros condicionais diretos no terminal, priorizando clareza de fluxo e boas práticas com tipos primitivos).*

## 💻 Exercícios Resolvidos

1. **Números Pares**: Lê $N$ números inteiros informados pelo usuário, armazena-os em um vetor, exibe na tela todos os valores pares e calcula a quantidade total de números que atendem ao critério.

## 🛠️ Tecnologias Utilizadas

- Java
- Ferramentas nativas: `Scanner`, arrays primitivos
