# ☕ Exercícios de Java - Vetores e Médias Aritméticas

Este repositório guarda os meus primeiros passos com arrays unidimensionais (vetores), focando especificamente em cálculo de médias aritméticas, acumulação numérica e filtragem de elementos com formatação de saída.

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Acumulação de valores e cálculo de média aritmética com divisão única
- Filtragem condicional comparando elementos de um vetor com um valor agregado
- Formatação de saída com precisão decimal arbitrária (`printf` com `%.3f` e `%.1f`)
- Controle de precisão numérica evitando divisões acumuladas em ponto flutuante

*(Nota de evolução: O código reforça o rigor com os requisitos do enunciado, garantindo formatação consistente de ponto flutuante tanto para valores agregados quanto para elementos individuais filtrados).*

## 💻 Exercícios Resolvidos

1. **Abaixo da Média**: Lê $N$ números reais em um vetor, calcula e exibe a média aritmética com três casas decimais e, em seguida, lista todos os valores que ficaram estritamente abaixo dessa média, formatados com uma casa decimal.

## 🛠️ Tecnologias Utilizadas

- Java
- Ferramentas nativas: `Scanner`, `Locale`, arrays primitivos (`double[]`)
