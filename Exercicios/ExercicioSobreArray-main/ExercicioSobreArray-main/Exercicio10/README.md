# ☕ Exercícios de Java - Vetores de Objetos e Encapsulamento

Este repositório guarda os meus primeiros passos com vetores de objetos (referências), focando especificamente em instanciação dinâmica de classes, encapsulamento e delegação de lógica de negócio para métodos de entidade.

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Vetores de tipos referência (`Aluno[]`) e prevenção de `NullPointerException`
- Modelagem de entidades com construtores, atributos privados e métodos de acesso (*getters/setters*)
- Delegação de comportamento: cálculo da média centralizado na classe de domínio
- Gerenciamento e limpeza contínua de buffer de entrada do `Scanner`

*(Nota de evolução: O código marca a transição crucial de arrays primitivos para arrays de classes customizadas, conectando a base de repetição com os princípios fundamentais da Orientação a Objetos).*

## 💻 Exercícios Resolvidos

1. **Aprovados**: Lê os dados de $N$ alunos (nome e notas semestrais) armazenando-os em um vetor de instâncias da classe `Aluno`, calcula a média semestral de cada estudante e exibe a lista dos aprovados com média igual ou superior a 6.0.

## 🛠️ Tecnologias Utilizadas

- Java
- Ferramentas nativas: `Scanner`, `Locale`, Orientação a Objetos (`Class`, `Constructor`, `Encapsulation`)
