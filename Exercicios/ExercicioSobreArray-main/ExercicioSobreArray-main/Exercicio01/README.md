# ☕ Exercícios de Java - Vetores (Arrays)

Este repositório guarda os meus primeiros passos com vetores em Java, focando especificamente na alocação de memória estática, iteração com ciclos for e filtragem condicional de elementos. 

## 🚀 O que eu estava aprendendo

Estes exercícios foram feitos bem no início dos meus estudos, focando em fazer a lógica funcionar e entender os conceitos fundamentais.

Nesta etapa, eu apliquei:
- Declaração e instanciação de vetores de tipos primitivos (`int[]`)
- Leitura de entradas do utilizador e armazenamento sequencial em índices de memória
- Uso da propriedade `.length` para controlo de limites de repetição
- Filtragem condicional para exibir apenas valores negativos

*(Nota de evolução: O código demonstra a separação correta entre o momento de alimentar o vetor e o momento de processar os dados armazenados).*

## 💻 Exercícios Resolvidos

1. **Problema Negativos**: Lê um número inteiro $N$ (máximo 10) e, em seguida, armazena $N$ valores num vetor, imprimindo no ecrã todos os números negativos encontrados.
